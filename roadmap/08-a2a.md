# 08 · A2A：agent-card 远程子代理（精简复刻）  ✅ 已完成

## Context

复刻 agent-2 的 **A2A（Agent-to-Agent）** 能力：通过 **agent-card 发现 + JSON-RPC 调用远程子代理**，
ADK 原生 A2A（`RemoteA2aAgent` 客户端 + `google.adk.a2a.to_a2a` 服务端 + `a2a-sdk`）。

### 真实源码映射
| demo | 真实 |
|---|---|
| `a2a_service/`（to_a2a 暴露子代理）| Java `A2AAgentRuntimeController`（`/runtime/jsonrpc/.../{agentInstanceId}`）|
| `skillcenter/a2a_api.py`（/instance/list 注册表）| Java `A2AAgentInstanceController`（`.well-known/agent-card.json` + `/instance/list`）|
| `agent/a2a/loader.py`（RemoteA2aAgent）| `app/core/agent/remote_agent/a2a/custom_remote_a2a_agent.py`（`RemoteA2aAgent` + a2a SDK）|

## 设计（4 个服务）

```
agent(:8000) ──/instance/list──▶ skill-center(:8200)（A2A 注册表，返回 cardUrl）
     │ 每实例 → AgentTool(RemoteA2aAgent(agent_card=cardUrl))
     ▼ 主代理调用工具
RemoteA2aAgent ──解析 agent-card + JSON-RPC message/stream──▶ a2a_service(:8300)
                                                              （ADK to_a2a 暴露 math_expert 子代理）
```

- **依赖闸门（K0）**：`a2a-sdk` 与 adk 2.3.0 对齐 = `>=0.3.4,<0.4`（最新 1.x 丢了 `ClientEvent`/`a2a.server.apps` 不兼容）。装 0.3.26 后 `RemoteA2aAgent` + `to_a2a` 可用；well-known 路径 `/.well-known/agent-card.json`。
- **服务端**：`a2a_service` 用 `to_a2a(math_expert, host, port)` 独立运行（card url 自动正确，避免挂载改写 url 的坑）；暴露 agent-card + JSON-RPC。
- **注册表**：skill-center `POST /api/v1/a2a-agents/instance/list` 返回 `{agentInstanceId, name, cardUrl}`（指向 a2a_service 的 agent-card）。
- **客户端**：`agent/a2a/loader.py` 拉 /instance/list → 每个建 `RemoteA2aAgent(name, agent_card=cardUrl)`（ADK 首次调用时按 well-known 解析）→ 包 `AgentTool` 注入 `ctx.tools`。**零改引擎**（A2A 子代理即一个工具，两代引擎共享）。

## 实施记录（E2E 通过）
- `py_compile` 全绿（98 文件）；`to_a2a` 服务 `/.well-known/agent-card.json` 返回 name=math_expert / url=http://127.0.0.1:8300 / skill 已注册。
- E2E：起 a2a_service+skill-center+agent，「用 A2A 数学专家算 23*47」→ 主代理调 `math_expert` AgentTool → RemoteA2aAgent 解析 card + A2A JSON-RPC → 远程 math_expert 计算 → 答 **1081**（正确）。`[A2ALoad] loaded` 启动加载。
- 文件：`a2a_service/{config,agents,main}`、`skillcenter/a2a_api.py`、`agent/a2a/loader.py`；接线 `context.attach_a2a_agents` + `main` + `skillcenter/{config,main}` + `requirements(a2a-sdk)`。

## 取舍 / 偏差
- A2A 运行时拆到独立 `a2a_service`（真实里 skill-center 内含 runtime jsonrpc）；skill-center 仅做注册表——避开 `to_a2a` 挂载 FastAPI 改写 agent-card url 的复杂度，更鲁棒。
- 1 个 A2A 子代理（math_expert）足以演示协议；poet 等可仿照扩展。
- **裁剪**：instantiate/create/update/delete/snapshot 管理、双快照、HSF。
- **裁剪：A2A JSON-RPC 上下文/header 透传**。生产 `StreamingRemoteA2aAgent` 会把执行上下文（用户/会话/agent）注入 JSON-RPC `metadata`，并透传 `X-Trace-Id`/`X-User-Payload`/Langfuse trace headers；Java `A2AAgentRuntimeController` 再从 metadata pop 出 `context` 映射为 `ExecuteContextVO`。demo 用公版 `RemoteA2aAgent(name, agent_card=cardUrl)`，**只复刻 agent-card 发现 + JSON-RPC 远程委派主链路**，未注入 `SkillToolExecuteContext`、未给 `a2a_service`（`to_a2a` 生成的 ASGI app）接 `TraceMiddleware`。如需增强可用 `RemoteA2aAgent` 的 `a2a_request_meta_provider` 把上下文映射成 metadata。
- ADK A2A 仍标注 EXPERIMENTAL（导入有 UserWarning，功能正常）。
